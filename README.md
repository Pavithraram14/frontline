# Frontline Technologies Website

A responsive 8-page static website for Frontline Technologies.

## Pages
- index.html — Home
- about.html — About and founder
- services.html — Call centre, BPO and IT services
- technologies.html — Technology capabilities
- careers.html — Career areas
- training.html — Learning and development
- contact.html — Contact details and demo enquiry form
- terms.html — Starter terms and privacy information

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet access is required for the Unsplash images.

## Important before publishing
- The contact form is front-end demo only. Connect it to a secure backend or form service to receive submissions.
- Career roles are illustrative categories, not confirmed live vacancies.
- Review the Terms & Privacy page with a qualified professional.
- Replace remote stock images with licensed company photos where possible.
- Confirm all business details and service claims before publishing.

## Customisation
Edit the HTML pages for content, `assets/style.css` for colours/layout, and `assets/script.js` for interactions.
